# gemini sdk

### **Gemini Service Foundation**

**Task 11.1: Gemini SDK Setup**

- Install @google/generative-ai SDK
- Configure API credentials (have 2-3 keys for redundancy)
- Test connection with simple prompt
- Understand rate limits and quotas
- Set up error handling and retries

**Task 11.2: Model Router**

- Create model selection logic:
    - Decision tree based on task type:
        - Simple classification → Flash
        - Complex reasoning → Pro
        - Image analysis → Vision
        - Code execution → Pro with code interpreter
    - Consider latency requirements:
        - User waiting → Flash (fast)
        - Background processing → Pro (thorough)
    - Track API costs and optimize
- Implement model instances:
    - flashModel: Gemini 2.0 Flash
    - proModel: Gemini 1.5 Pro
    - visionModel: Gemini Pro Vision
- Add automatic fallback:
    - If Pro fails, retry with Flash
    - If all models fail, use cached response or simple heuristic

**Task 11.3: Prompt Engineering**

- Create prompt templates for common tasks:
    - Intent classification
    - Transaction categorization
    - Spending analysis
    - Financial advice generation
    - Response structuring
- Implement prompt builder:
    - Takes template and fills in variables
    - Adds conversation history if relevant
    - Includes user context
    - Formats consistently for Gemini
- Build prompt optimization:
    - Track which prompts get best results
    - A/B test prompt variations
    - Refine based on user feedback

**Task 11.4: Response Parsing**

- Create response parsers:
    - JSON parser (for structured data)
    - Text parser (for natural language responses)
    - Confidence score extractor
    - Entity extractor (pull out key facts, numbers)
- Handle malformed responses:
    - Retry with clarification prompt
    - Use partial results if possible
    - Fallback to simple response
- Validate Gemini outputs:
    - Check required fields present
    - Verify data types
    - Sanitize for safety (no injection attacks)

**Deliverable:** Gemini service routing requests to appropriate models

### **Hour 27-30: Core Intelligence Features**

**Task 12.1: Intent Classification Implementation**

- Build classification pipeline:
    - Preprocess user message (clean, normalize)
    - Inject conversation context
    - Call Gemini Flash with classification prompt
    - Parse intent, confidence, and entities
    - Cache result (same message shouldn't be reclassified)
- Create intent mapping:
    - Map intent to agent
    - Map intent to required data (what needs to be fetched)
    - Map intent to response type (quick answer vs deep analysis)
- Implement confidence thresholds:
    - High (>70%): Route immediately
    - Medium (40-70%): Ask clarification
    - Low (<40%): Default to Nova, ask user to rephrase

**Task 12.2: Transaction Categorization**

- Build categorization system:
    - Gemini analyzes merchant name and description
    - Returns category (Groceries, Dining, Entertainment, etc.)
    - Returns sub-category (Groceries → Supermarket vs Convenience)
    - Returns tags (healthy, luxury, necessity)
- Implement smart categorization:
    - Learn from user corrections (if user recategorizes, remember)
    - Consider transaction amount (high amount at grocery store might be bulk shopping)
    - Look at time of day ($50 at restaurant at 7pm = dinner, at 2pm = lunch for group)
- Add batch categorization:
    - Categorize multiple transactions at once (more efficient)
    - Use patterns (all transactions at this merchant are "Gas")
    - Cache merchant categories

**Task 12.3: Spending Analysis**

- Implement pattern detection:
    - Gemini analyzes transaction history
    - Identifies patterns:
        - Time-based (more spending on weekends)
        - Event-based (spending spikes after stressful events)
        - Cyclical (higher bills in summer/winter)
        - Emotional (stress spending, celebration spending)
    - Returns structured insights
- Build comparison engine:
    - Current month vs last month
    - Current spending vs budget
    - User vs peer averages (anonymous benchmarking)
    - Trend analysis (increasing, decreasing, stable)
- Create insight generator:
    - Gemini generates natural language insights
    - Includes: observation, context, impact, recommendation
    - Tailored to user's goals and situation

**Task 12.4: Response Structure Generation**

- Build response structurer:
    - Takes raw analysis results
    - Creates blueprint for agent response
    - Includes: key points, tone guidance, emphasis words
    - Suggests follow-up questions
- Implement layered content:
    - Essential layer (direct answer)
    - Context layer (why it matters)
    - Action layer (what to do)
    - Education layer (learning opportunity)
- Add delivery instructions:
    - Tone (joyful, concerned, urgent, celebratory)
    - Pacing (fast for exciting news, slow for complex info)
    - Emphasis (which words to stress)
    - Pauses (where to pause for effect)

**Deliverable:** Core Gemini intelligence features powering agent

# Gemini

Gemini is the **cognitive engine** that powers agent intelligence. It does NOT replace agents; it makes them smarter.

**Core Functions:**

1. Intent classification and routing
2. Context analysis and enrichment
3. *Complex reasoning and planning*
4. *Multimodal understanding (text, images, documents)*
5. Function calling orchestration
6. Response structure generation
7. Educational content creation

**Gemini Integration Architecture**

**Model Selection Strategy:**

**Gemini 2.0 Flash (Speed-Critical Operations):**

- Use for: Real-time intent classification, quick queries, simple categorization
- Response time target: <500ms
- Cost: Lower
- Examples:
    - "Is this a spending question or investment question?"
    - "Categorize this transaction: $45 at Starbucks"
    - "Which agent should handle: 'Can I afford a vacation?'"

**Gemini Pro 1.5 (Complex Reasoning):**

- Use for: Multi-step planning, scenario analysis, document understanding
- Response time: 2-5 seconds (acceptable for complex questions)
- Cost: Higher but justified
- Examples:
    - "Create a debt payoff plan with 3 different strategies"
    - "Analyze this 40-page contract and explain the fees"
    - "Model retirement scenarios with varying contribution rates"

**Gemini Vision:**

- Use for: Receipt scanning, chart analysis, document extraction
- Response time: 1-3 seconds
- Examples:
    - "Extract all items and prices from this restaurant receipt"
    - "Read this utility bill and identify the charges"
    - "Analyze this bank statement and flag unusual items"

**Model Router Logic:**

- Orchestrator determines which model to use based on:
    - Task complexity (simple → Flash, complex → Pro)
    - Latency requirements (user waiting → Flash, background → Pro)
    - Input type (image → Vision, text → Flash/Pro)
    - Cost budget (prefer Flash when possible)

**Intent Classification System**

**Purpose:** Determine user's goal from natural language input

**Process:**

**Step 1: Message Preprocessing**

- Clean transcription (remove filler words: um, uh, like)
- Correct common speech-to-text errors
- Expand contractions (can't → cannot)
- Normalize variations (gonna → going to)

**Step 2: Context Injection**

- Provide Gemini with:
    - Current conversation history (last 5 turns)
    - User's recent activity (transactions today)
    - Active financial projects
    - User profile summary
- Format as system context

**Step 3: Intent Classification Prompt**

- Structured prompt to Gemini Flash:
    - "Given this user message and context, classify the intent"
    - Provide intent taxonomy (spending, investing, general (Nova))
    - Provide confidence scores (0/1)
    - Request agent recommendation

**Step 4: Parse Classification Result**

- Gemini returns:
    - Primary intent: "spending_analysis"
    - Confidence: bool, fallback general (Nova)
    - Recommended agent: "Nebula"
    - *Secondary intents: ["budget_concern"] (20%)*
    - Key entities: ["coffee", "last_week", "$87"]
    - Sentiment: "concerned"

**Step 5: Routing Decision**

- If confidence 1: Route to recommended agent
- If confidence 0: Fallback to Nova with request to ask for clarification

**Intent Taxonomy:**

**Primary Categories:**

- spending_analysis: Understanding past spending (Nebula)
- budget_management: Creating or adjusting budgets (Nebula)
- savings_goal: Setting or tracking savings goals (Nebula)
- investment_question: Anything about investing, retirement, wealth (Atlas)
- financial_forecast: Future planning, "what if" scenarios (Nebula)
- financial_education: Learning about concepts (Nova)
- account_management: Opening accounts, transfers (Nova)
- general_inquiry: Small talk, app usage questions (Nova)

### **Context Analysis and Enrichment**

**Purpose:** Understand the full picture beyond the literal question

**Process:**

**Step 1: Historical Pattern Analysis**

- Query user's transaction history
- Identify spending patterns:
    - Average spending by category
    - Spending trends (increasing/decreasing)
    - Cyclical patterns (more spending on weekends)
    - Seasonal variations (higher utility bills in summer)
    - Merchant loyalty (frequents certain stores)
- Compare current activity to historical baseline

***Step 2: Behavioral Signals***

- *Analyze conversation tone and word choice*
- *Detect emotional state:*
    - *Anxiety: "worried", "stressed", "scared"*
    - *Excitement: "finally", "amazing", "yes!"*
    - *Confusion: "don't understand", "confused", "complicated"*
    - *Frustration: "why", "always", negative language*
- *Identify life events:*
    - *Job change (new income pattern)*
    - *Moving (address change, utility changes)*
    - *Relationship change (rent splitting)*
    - *Health event (medical bills)*
    
    **Step 3: Financial Health Assessment (For financial coaching and generating reports)**
    
- Calculate real-time metrics:
    - Debt-to-income ratio
    - Emergency fund adequacy (months of expenses)
    - Savings rate (% of income)
    - Spending volatility (how erratic)
    - Bill payment consistency
- Compare to goals and benchmarks
- Flag concerning trends

**Step 4: Goal Progress Tracking**

- Review active financial goals
- Calculate progress percentage
- Project completion date at current rate
- Identify blockers or accelerators
- Prepare celebration triggers (milestones hit)

**Step 5: Context Package Creation**

- Bundle all analysis into structured format
- Attach to conversation context
- Make available to agent
- Update context as new information emerges

**Enrichment Examples:**

**User asks: "How much did I spend on coffee this week?"**

**Literal answer:** "$87"

**Enriched context:**

- Historical average: $60/week
- Trend: 45% above normal
- Pattern: All purchases on Monday, Wednesday, Friday mornings
- Correlation: Purchases align with late meetings previous evening
- Emotional trigger: Likely stress-related
- Budget impact: Coffee category is 20% over monthly budget
- Opportunity: Reducing to average would save $108/month = $1,296/year

**Agent response (enriched by Gemini):**
"You spent $87 on coffee this week, which is $27 more than your usual $60. I noticed all your coffee runs happened the mornings after you had late meetings. Seems like coffee is your stress relief! That's totally understandable, but this pattern is pushing your coffee budget 20% over target. Want to talk about some alternatives that might help with the stress without the expense?"

==============================================================================

✅ All agents receive 60-min cached data from API layer
   - Layer 1: Memory (5 min)
   - Layer 2: File (60 min) ← API Layer!

   - Orchestrator executes tools
   - Results are cached
   - Agents receive pre-computed context

   - If API fails → use stale cache
   - If cache empty → return error with context
